Set up SafePaste

SafePaste uses a local AI model, run by Ollama, to find names and other private details before you paste. The check runs on this computer. The text you paste still goes to the AI site, with placeholders instead of the private details.

1 Install Ollama

Ollama runs AI models on your computer. Install it and open it. This page notices when it's running.

Download Ollama

2 Allow SafePaste to use Ollama

Ollama only accepts requests from apps you allow. Run this once in a terminal, then restart Ollama.


            

        


        

            
3 Download the AI model

            
The model  is downloaded once and stays on this computer.
